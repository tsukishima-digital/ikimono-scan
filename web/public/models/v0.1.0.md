# 甲虫判定モデル v0.1.0

このモデルは、日本で観察される甲虫422分類群を画像から分類する非営利用のEfficientNet-B0です。クビアカツヤカミキリを重点対象にしています。

## 学習データと利用根拠

日本国内のiNaturalist research grade observationsから取得した画像を15,520枚使用しました。画像の表現を再現するためではなく、生物分類の特徴を情報解析するための学習です。日本の著作権法第30条の4と[文化庁のAIと著作権に関する整理](https://www.bunka.go.jp/seisaku/chosakuken/aiandcopyright.html)に基づき、著作物に表現された思想・感情の享受を目的としない情報解析として扱います。[iNaturalist利用規約](https://www.inaturalist.org/pages/terms)が禁止する商用AI学習と整合させるため、モデルも非商用に限定します。

写真のライセンス未指定またはNDを理由に画像を除外していません。これらの画像はCreative Commonsライセンスによる許諾ではなく、上記の権利制限規定を利用根拠としています。モデルは入力写真を生成または復元する機能を持たない識別モデルです。将来、学習画像と類似する表現を出力できる構成へ変更する場合は、この判断を再利用しません。

## モデルと評価

- architecture: EfficientNet-B0
- input: RGB 320 × 320
- classes: 422
- validation images: 3,188
- validation accuracy: 0.7971
- macro F1: 0.7771
- weighted F1: 0.7922
- Aromia bungii precision / recall / F1: 0.9130 / 0.9545 / 0.9333
- checkpoint SHA-256: `a49787380c265ee9542cd2ce40d914f37e7bf630e32ea4e851ab63afc6e5839d`
- ONNX SHA-256: `91f2da381a0528e464f75317a0eda94d81519ce40a103ce71698a85a210a97ee`

ONNXとPyTorch checkpointへ同じ固定入力を与えた比較では、最大絶対誤差は`4.30e-6`未満で、最上位クラスは一致しました。

この評価値は学習時に固定したvalidation split上の値です。未対応の生物、甲虫以外、不鮮明な画像、撮影条件の偏りに対する性能を保証しません。
