# 重点種台帳

重点種台帳は、判定結果が利用者の行動や保全に影響する種について、公式な位置付けとIkimono Scanの評価方針を記録します。学習時のサンプリング倍率やloss weightは台帳に含めません。学習条件は台帳の重点度、誤判定リスク、識別グループ、利用可能な画像数を入力として別途決定します。

台帳は全国制度を対象に、次の公式ソースを監視します。

- 環境省「特定外来生物等一覧」
- 環境省「生態系被害防止外来種リスト」
- 環境省「国内希少野生動植物種一覧」
- 環境省「レッドリスト・レッドデータブック」

特定外来生物は、環境省が公表する162種類の指定スコープをすべて台帳へ保存します。属・科の全種、交雑個体、除外対象を含む指定は、個別の種へ展開せず公式表の記述を維持します。アカミミガメとアメリカザリガニは、一部の規制が適用除外となる条件付特定外来生物として通常の指定と区別します。

都道府県のレッドリストや自治体独自の通報・報奨制度は、全国制度と混同しないよう対象地域と有効期間を持つ情報として扱います。

## 重点度

P0は、偽陽性または偽陰性が駆除、捕獲、保護などの行動へ直接影響し得る種です。P1は法的な取扱いや保護行動に関係する種、P2は保全・観察上の情報価値が高い種です。特定外来生物と条件付特定外来生物は、法的な取扱いが生じるため指定スコープ全体をP1とします。P0への引き上げは、想定される行動と誤判定時の影響を個別に確認します。他の公式リストは、掲載だけで重点度を自動決定しません。

クビアカツヤカミキリは、見逃しによる拡散と、在来のカミキリムシを誤って防除する可能性の両方があるためP0です。比較対象は日本で観察される同科の種を起点とし、モデルが実際に混同した種と、取り違え時に行動が逆になる種を追加します。条件付特定外来生物のアメリカザリガニ、アカミミガメ、ミシシッピアカミミガメはP1として、法的な取扱いと類似する在来種を確認対象にします。

## 公式情報の更新

GitHub Actionsが週に一度、公式4ページからナビゲーション、script、styleを除いた本文を正規化し、台帳に保存したSHA-256と比較します。変更時は同じ未解決Issueへ確認依頼を追加します。ページ構成変更と制度変更を機械的に区別できないため、ステータスや学名は自動更新しません。

Issueを受けた担当者は、公式発表の施行日、対象分類群、学名・和名、既存taxon IDとの対応を確認します。特定外来生物の指定スコープを再生成し、taxon IDとの対応と重点度をレビューしてから、確認済みの本文指紋を更新します。これらは同じpull requestでレビューします。

```console
task priority:specified:refresh
task priority:sources:refresh
task priority:check
```

環境省レッドリストは分類群ごとに最新版が異なるため、個々のステータスへ根拠ソースと確認日を保持します。公式名とiNaturalist上の採用名が一致しない場合は、名称だけで自動対応せず人手でtaxon IDを確認します。
