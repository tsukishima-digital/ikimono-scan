# 生物ステータス・制度台帳

生物ステータス・制度台帳は、生物の法的・保全上の位置付けと、国や自治体が実施する通報・捕獲・捕殺・回収制度の事実を記録します。重点度、誤判定の影響度、学習時のサンプリング倍率、識別対象の選び方は含めません。モデルの評価・学習計画は、台帳の事実と利用可能な画像数を参照して別途決定します。

台帳は全国制度を対象に、次の公式ソースを監視します。

- 環境省「特定外来生物等一覧」
- 環境省「生態系被害防止外来種リスト」
- 環境省「国内希少野生動植物種一覧」
- 環境省「レッドリスト・レッドデータブック」

特定外来生物は、環境省が公表する162の指定スコープをすべて保存します。属・科の全種、交雑個体、除外対象を含む指定は、個別の種へ展開せず公式表の記述を維持します。アカミミガメとアメリカザリガニは、一部の規制が適用除外となる条件付特定外来生物として通常の指定と区別します。

## 自治体制度

自治体制度は、制度の対象地域、実施期間、根拠ソース、確認日を保存します。対象生物、対象者、求められる行動、報奨は同じ`participationPolicies`レコードへ保持し、異なる制度や参加条件の最大値を組み合わせません。たとえば、一般市民への通報依頼と登録従事者への捕殺依頼から「一般市民への捕殺依頼」を生成することは禁止します。

初期データとして、茨城県の2026年度「いばらきカミキリみっけ隊」を収録しています。茨城県民への通報依頼と、小学生以上の県民を対象とする成虫の捕獲・捕殺・死骸提出および10匹につき500円相当の奨励金を別の参加条件として記録しています。対象はクビアカツヤカミキリとツヤハダゴマダラカミキリです。

自治体制度は地域・年度・予算によって開始、変更、早期終了するため、単純な全国共通の「捕殺対象」フラグへ変換しません。学習計画で必要な場合は、基準日現在で有効な制度を抽出し、対象者と行動の組み合わせを維持したまま判断します。現在の収録範囲は網羅的な全国調査ではありません。

## 公式情報の更新

GitHub Actionsが週に一度、公式ページからナビゲーション、script、styleを除いた本文を正規化し、台帳に保存したSHA-256と比較します。変更時は同じ未解決Issueへ確認依頼を追加します。ページ構成変更と制度変更を機械的に区別できないため、ステータスや自治体制度は自動更新しません。

Issueを受けた担当者は、公式発表の施行日、対象分類群、学名・和名、既存taxon IDとの対応を確認します。自治体制度は対象地域、期間、対象者、行動、報奨を同じ根拠ソースで確認します。確認後、次のコマンドで指定スコープと本文指紋を更新し、同じpull requestでレビューします。

```console
task species-status:specified:refresh
task species-status:sources:refresh
task species-status:check
```

環境省レッドリストは分類群ごとに最新版が異なるため、個々のステータスへ根拠ソースと確認日を保持します。公式名とiNaturalist上の採用名が一致しない場合は、名称だけで自動対応せず人手でtaxon IDを確認します。
